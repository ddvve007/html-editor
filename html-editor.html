HTML 编辑器 · 使用说明

日常只用四步：打开 → 编辑 → 预览 → 下载

编辑：双击改字、拖动排版；内容区按钮不会执行原动作。预览：使用课件的按钮、选择卡与下拉框。导航和翻页始终可用。工具条可拖动，“＋”展开插入选择；层级、删除等按钮直接显示，悬停查看说明。顶部HTML源码按钮：查找、修改完整源码并应用。

可视化编辑改变页面显示；若要修改复制内容、计算公式或内嵌数据，请用HTML源码。修改动态课件后，务必下载新文件，并重新打开检查。

给网页报告加批注、调版式的浏览器小工具 —— 无需安装，双击就能用。
适用于 Chrome / Edge / Safari · 编辑器本机处理 · 原网页外部资源按原配置加载

1这是什么

把一份网页报告（.html 文件）拖进编辑器，即可直接在页面上修改文字、插入形状、调整位置和大小、改边框底色。改完点“下载HTML”得到一份新文件，发给别人、投影、存档都不受影响。

2三步上手

  1. 拖入文件——把要编辑的 HTML 拖到窗口任意位置，松手即载入；或点「打开HTML」选择。
  2. 开始编辑——单击选中任意元素（文字、图、卡片），拖动移位、拉手柄缩放；底部工具条加形状、改颜色、调字号。
  3. 下载HTML——点顶部「下载HTML」，新文件下载到浏览器「下载」文件夹。
没有安装步骤、没有账号、不联网也能用——这是一个「文件」，不是软件，换电脑把它复制过去即可。可加入浏览器书签随时打开。

3功能清单

选择与移动

操作效果
单击元素选中（蓝色选框）
Shift + 单击加选 / 取消加选，可多选一起移动
拖动移动元素；方向键微调（1px）
工具条「选择上一级」按钮从内部元素跳到外层容器（如单元格 → 表格）
双击文字直接改字（页面里的图表文字也可以）

缩放

文本框拖左右手柄调整宽度，拖上下手柄调整高度；字号保持不变。拖角点可自由调整，按住Shift拖角点可等比调整框体。字号使用A- / A+按钮。

操作效果
拖四角手柄自由调整宽和高
按住 Shift 拖角等比缩放（不变形）
拖四边手柄上下＝只调高度，左右＝只调宽度

插入形状与标注（底部工具条 → 插入）

  • 方框 / 圆形 / 圆角方形：点击即插入到画面中央；可拖动、缩放、改边框色和底色
  • 线条：默认带箭头，可开关箭头、切换实线 / 虚线；两端小圆点可拖动调长度和角度
  • 文本：插入后直接输入文字，可改字号、颜色
  • 图片：点图片按钮选本地图片，自动插入；图片内嵌进文件，导出后不丢

层级：元素被其他内容遮挡时，选中它点「置于顶层」（方框上箭头）浮到最上方，「置于底层」（方框下箭头）沉到下层；可撤销。

颜色：选中元素后点工具条“颜色”，面板会按选中对象区分「文字颜色 / 文字底色」与「边框颜色 / 填充底色」——边框改线条颜色（形状、表格、卡片都行，原本没边框的会自动补上）；底色改填充（表格连单元格一起变）。12 个常用色 + 自定义拾色器。

文字：A− / A+ 调字号、B 加粗；调色板「文字颜色」模式可改文字颜色。

撤销与删除：⌘Z（Mac）/ Ctrl+Z（Win）撤销 30 步；删除按钮删除选中元素（可撤销）；Esc 退出编辑 / 取消选中。

工具条位置：按住工具条“拖动”处或空白处（按钮以外）可拖到任意位置，不再挡住内容；同一次使用期间，重新载入文件会保留位置。

4保存与导出

  • 点顶部「下载HTML」→ 下载一份新文件（原文件不受影响）
  • 暂存进度：改到一半不想下载文件？点顶部「暂存到浏览器」图标——进度存在你的浏览器里；下次打开同一个文件时可以「恢复继续编辑」。全部改完，最后点一次「下载HTML」就是最终版（下载时也会自动暂存一份）
  • 导出文件不含任何编辑器痕迹——发给别人、投屏播放都看不到工具条
  • 想继续改：把导出文件再拖进编辑器即可（标注内容都还在）
建议在副本上操作：先复制一份原文件，拖副本进来改。原稿永远安全。
动态翻页报告，修改会自动保持：很多 AI 生成的 HTML 演示「每次翻页会重画页面」，编辑器已内置「修改保持」——翻页来回、以及导出的新文件里，修改都不会丢。改完所有页最后点一次「下载HTML」即可，不需要逐页保存。

5常见问题

拖进去没反应？

确认文件拖到的是编辑器窗口内部（整个窗口都可以）。若浏览器询问"打开还是下载"，选"打开"。

保存的文件去哪了？

浏览器「下载」文件夹（列表里最新的那个）。

我的文件会被上传吗？

编辑器自身在本机处理文件，无账号；导入网页原有的外部资源或脚本仍按其配置运行。

能编辑哪些文件？

网页报告、数据看板类的 .html 文件。翻页式汇报支持最完整；普通长网页也支持改文字、加形状、调颜色。

改坏了怎么办？

立刻按 ⌘Z 撤销；保存后才发现，重新拖入原文件重做即可（下载HTML不会覆盖原文件）。

改到一半关了浏览器，修改会丢吗？

点过「暂存进度」（或下载、保存过一次）就不会——重新打开编辑器、载入同一个文件时，选「恢复继续编辑」即可接着改。没暂存过则无法找回。
