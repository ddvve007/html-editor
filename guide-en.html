Four steps: Open → Edit → Preview → Download

Edit: double-click text to change it, drag elements to reposition them. Content buttons do not run their original actions in Edit mode. Preview: use the imported page’s buttons, cards and dropdowns. Page navigation remains available in both modes. Drag the toolbar to move it; use + to insert elements. Hover over icons for their names. Use HTML source to find and edit the complete source.

Visual editing changes the displayed page. To change copied text, formulas, embedded data or interaction logic, use HTML source. After editing a dynamic page, download and reopen the new file to check it.

1What is HTML Editor?

A browser tool for editing .html and .htm files: reports, dashboards, presentations and ordinary web pages. Edit text, insert shapes and images, resize objects, change colors and adjust layouts. Download a new HTML file to share, present or archive.

No installation or account is needed. The editor processes files locally and does not upload them. Imported pages can still run their scripts and load their original external resources. Only open HTML files you trust.

2Getting started

  1. Open: drop an HTML file anywhere in the editor or choose Open HTML.
  2. Edit: click to select; double-click text to edit. Drag to move; use handles to resize.
  3. Preview: test the page’s buttons and interactions, then switch back to Edit as needed.
  4. Download: choose Download HTML and check your browser’s Downloads folder.
Download either standalone editor file for offline use. Files that depend on online resources still need those resources to display correctly.

Resize text boxes: side handles change width or height without changing font size. Corner handles change both; Shift + corner drag preserves proportions. Use A− / A+ for font size.

Insert: text, embedded local images, rectangles, circles, rounded rectangles and lines. Lines have optional arrows, draggable endpoints and solid/dashed styles.

Stacking order: Bring to front / Send to back control overlap. Color: the palette shows Text color / Text background for text, and Border color / Fill color for shapes or containers. Choose a preset or custom color. Toolbar: drag the empty area or Drag handle; its position stays during the current session.

4Saving

  • Download HTML creates a new -edited.html file. Your original stays intact. Reimport the result to continue editing.
  • Save draft in browser stores work in this browser, subject to storage limits. Reopening the same filename can offer Resume draft. Drafts do not transfer to another browser or computer.
  • Downloads also attempt to save a draft. A draft is not the final deliverable: download the HTML file before sharing.
  • Exports remove editing controls and preserve the page’s scripts, embedded images and supported persistent edits.
  • The optional Save to original control is available only for supported local URL workflows and requires a separate local service on port 8777; that service is not bundled.
Supported dynamic HTML decks retain edits across redraws and page changes. React/Vue apps, hydration, network-fed data and cross-origin frames may need adaptation. Always reopen the downloaded file and test its interactions.

5Common questions

Where is my downloaded file?

In the browser’s Downloads folder or the destination you selected. Check the download list after the editor says the download has started.

Can I open a URL?

Yes, if the remote server allows cross-origin access. Local HTML files are the simplest option.

Will changes survive closing the browser?

Only changes saved in a draft or downloaded file can be recovered. Browser storage can be blocked, full or cleared.

How do I recover from a mistake?

Undo immediately. If necessary, reopen the original HTML and edit it again.
